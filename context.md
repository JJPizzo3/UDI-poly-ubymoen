Initial generation: U by Moen smart shower plugin (REST + Pusher cloud client). Controller discovers showers; one shower node per device with power, temperature, mode, preset, timer and 4 outlet toggles. Protocol derived from MIT-licensed WeaveHubHQ/mrworf ha-u-by-moen. moen_client.py builds its helper classes with type() because the scaffold treats every 'class' statement in a node-class file as a device node.
